# 📊 Tech Job Escape India

## 📌 Project Overview

Tech Job Escape India is a Power BI dashboard created to analyze
Indian technology job data and identify meaningful insights
about job demand, salaries, skills, experience levels and work modes.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization

## 📊 Dashboard Preview

![Tech Job Escape India Dashboard](dasboard .png.png)

## 📈 Key Analysis

- Total Jobs
- Total Applicants
- Total Openings
- Average Salary
- Average Rating
- Job Demand
- Experience Level
- Top Hiring Cities
- Top In-Demand Skills
- Work Mode Distribution
- Salary by Location Tier

## 🔍 Key Insights

The dashboard helps understand hiring trends, in-demand skills,
salary patterns and work-mode preferences in the Indian tech job market.
